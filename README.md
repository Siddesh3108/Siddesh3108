### 📅 Timetable Generator
> *Production-grade academic scheduling engine that solves NP-hard constraint satisfaction using Google OR-Tools CP-SAT Solver.*

**Stack:** `Python` `Flask` `React.js` `TailwindCSS` `PostgreSQL` `Redis` `Celery` `Docker` `Nginx`

```
React.js (Vite)  →  Nginx (Reverse Proxy)  →  Flask + Gunicorn
                                                      ↓
                       Redis Queue  ←→  Celery Worker (CP-SAT Solver)
                                                      ↓
                                            PostgreSQL Database
```

- 🧮 **Google OR-Tools CP-SAT Solver** for constraint optimization
- ⚙️ Async task queue via **Celery + Redis** for non-blocking scheduling
- 🐳 Fully containerized with **Docker Compose** for reproducible deployment
- ⚡ Conflict detection & infeasibility diagnosis in seconds
- 📊 Workload analysis & data-driven insights for departments
